# Knowledge Base

Base de conocimiento personal de programación y herramientas de desarrollo. Nació como una colección de comandos de Git/GitHub y se fue ampliando para cubrir otros lenguajes y temas técnicos a medida que los voy aprendiendo.

## Estructura

- [`git-github/`](git-github/) — comandos y notas de Git y GitHub.
- [`python/`](python/) — notas de Python.
- [`cpp/`](cpp/) — notas de C++.
- [`asm/`](asm/) — notas de ensamblador.
- [`matlab/`](matlab/) — notas de MATLAB.
- [`terminal-ssh-networking/`](terminal-ssh-networking/) — terminal, SSH y redes locales.

Cada carpeta contiene notas propias, no documentación oficial reemplazada — son apuntes de cosas aprendidas en el día a día.
