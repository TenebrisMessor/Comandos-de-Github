# Explorando el Cómputo Paralelo

## Optimizando el rendimiento computacional. 

El cómputo paralelo implica la ejecución de múltiples instrucciones al mismo tiempo. 

Paralelo -> folder -> trabajo (Permite ejecutar varias tareas al mismo tiempo. Se divide la actividad principal para reducir tiempos de ejecución) 
Secuencial -> Cada instrucción se eecuta una vez que la inmediata anterior ha terminado. 

Cómputo Paralelo:
No es para todos los problemas. 

## Tipos de Cómputo Paralelo
### Una Herramienta para cada Escenario 


Hilos.
útiles para:

- Lectura y escritura de archivos
- Operaciones de base de datos.
- Operaciones de espera
- Operaciones de minitoreo
- Operaciones de descarga de datos

Procesos. 
Útiles para: 

- Procesamiento de imágenes y video.
- Procesamiento de datos a gran escala
- Renderizado de gráficos y animaciones
- Criptografia
- Entrenamiento de modelos matemáticos 
- Simuolaciones físicas o numéricas.
