# Que es Python?

Lenguaje de programación. Es un conjunto de componentes sintactico sy semanticos para ordenador. 

## Lenguajes de programación compilados o interpretados

Los compilados son los lenguajes de programación que se traducen desde un lenguaje de alto nivel y se transforma a código maquina.

Los interpretados no hacen la base de conversión sino que realiza una ejecución instantanea como en la consola de comandos.
